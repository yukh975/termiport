# TermiPort

Терминал и SSH-клиент для macOS со сквозным шифрованием синхронизации.

Нужна macOS 13.3 или новее, Apple silicon или Intel.

🇬🇧 [English version](README.md)

## Скачать

Последняя версия — в [Releases](../../releases/latest):

- `TermiPort_VERSION_aarch64.dmg` — Apple silicon (M1 и новее)
- `TermiPort_VERSION_x64.dmg` — Intel

Что изменилось в каждой версии — [CHANGELOG](CHANGELOG.ru.md).

Откройте .dmg и перетащите TermiPort в «Программы». Приложение не
нотаризовано Apple, поэтому первый запуск надо разрешить один раз: откройте
TermiPort, затем Системные настройки ▸ Конфиденциальность и безопасность ▸
«Всё равно открыть».

## Возможности

- SSH: хосты, группы, ключи, jump-хосты, known hosts
- Ключи: файловые, в Secure Enclave с Touch ID, аппаратные FIDO2
- Проброс агента через встроенный агент
- Проброс портов: локальный, удалённый, динамический (SOCKS)
- SFTP
- Локальный терминал (оболочка самого Мака) и serial-подключения
- Синхронизация со сквозным шифрованием

## Безопасность и синхронизация

- Всё хранится в локальном хранилище, зашифрованном мастер-паролем; на этом
  Маке его можно открывать и по Touch ID.
- Синхронизация не обязательна. Записи покидают Мак зашифрованными ключом,
  который есть только у ваших устройств; сервер не видит ни хостов, ни
  логинов, ни ключей, ни имён устройств.
- Новому устройству нужны только пароль аккаунта и второй фактор, если он
  включён (приложение-аутентификатор или FIDO2-ключ), после чего оно сразу
  синхронизируется.
- Код восстановления показывается один раз при создании аккаунта.
  Сохраните его на крайний случай.

## Лицензии

- Синхронизация бесплатна для 3 активных устройств на аккаунт. Отозванные
  устройства не считаются.
- Лицензия поднимает лимит устройств. Она привязана к email аккаунта, а не
  к серверу, и действует на любом сервере TermiPort.
- Устанавливается в **Settings ▸ License ▸ Install License…**.
- После окончания лицензия работает ещё 14 дней. Затем снова действует
  бесплатный лимит: полную синхронизацию сохраняют самые старые устройства
  аккаунта, остальные переходят в режим только чтения. Ничего не удаляется.

## Обновления

TermiPort ищет новую версию при запуске и по **TermiPort ▸ Check for
Updates…**, показывает, что изменилось, и ставит только обновления,
подписанные разработчиком.
